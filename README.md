# Fellowship Raid 🐉

친구들과 함께 즐기는 **웹 기반 실시간 협동 레이드 게임**.

5~10명이 탱커/힐러/딜러 역할을 나눠, 예고 패턴을 쓰는 보스를 협동으로 공략하는 탑다운 2D 게임입니다.

- **플랫폼**: 웹 브라우저
- **인원**: 5~10명 실시간 협동
- **장르**: 협동 레이드 (WoW 레이드 / 펠로우십 스타일)

자세한 설계는 [DESIGN.md](./DESIGN.md)를 참고하세요.

---

## 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
npm install

# 2. 서버 + 클라이언트 동시 실행
npm run dev
```

- 클라이언트: http://localhost:5173
- 서버: ws://localhost:2567
- **브라우저 탭을 여러 개 열면** 각 네모가 서로에게 실시간으로 보입니다. WASD 또는 방향키로 이동.

### 프로젝트 구조
```
packages/
├── shared/   # 서버·클라 공유 상수/타입
├── server/   # Colyseus 권한 서버 (실시간 시뮬레이션)
└── client/   # PixiJS 렌더링 + 입력
```

### 조작
- **이동**: WASD / 방향키
- **기본 공격**: 마우스 좌클릭(홀드) — 조준 방향 근접 스윙
- **스킬**: Q 또는 우클릭 — 조준 지점 광역 폭발 (마나 소모)

## 상태

✅ **Phase 0 완료** — 모노레포 + 실시간 동기화 검증 (최대 관문 통과)

✅ **Phase 2 완료** — 전투 기본기
  - HP/마나, 기본 공격(근접 부채꼴), 스킬(광역 폭발+쿨다운+마나)
  - 연습용 더미: 협동 타격 → 처치 → 자동 리스폰
  - 타격 이펙트 + 대미지 숫자 표시
