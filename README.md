# BORO Raid 🐉

친구들과 함께 즐기는 **웹 기반 실시간 협동 레이드 게임**.

5~10명이 탱커/힐러/딜러 역할을 나눠, 예고 패턴을 쓰는 보스를 협동으로 공략하는 탑다운 2D 게임입니다.

- **플랫폼**: 웹 브라우저
- **인원**: 5~10명 실시간 협동
- **장르**: 협동 레이드 (WoW 레이드 / 펠로우십 스타일)

자세한 설계는 [DESIGN.md](./DESIGN.md)를 참고하세요.

---

## 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
npm install

# 2. 서버 + 클라이언트 동시 실행
npm run dev
```

- 클라이언트: http://localhost:5273
- 서버: ws://localhost:2567
- **브라우저 탭을 여러 개 열면** 각 네모가 서로에게 실시간으로 보입니다. WASD 또는 방향키로 이동.

### 프로젝트 구조
```
packages/
├── shared/   # 서버·클라 공유 상수/타입
├── server/   # Colyseus 권한 서버 (실시간 시뮬레이션)
└── client/   # PixiJS 렌더링 + 입력
```

### 조작
- **이동**: WASD / 방향키
- **기본 공격**: 마우스 좌클릭(홀드) — 조준 방향 근접 스윙
- **역할 스킬(Q / 우클릭)**: 역할별로 다름 (탱커=도발 / 힐러=광역치유 / 딜러=광역폭발)
- **역할 전환**: `1` 탱커 · `2` 힐러 · `3` 딜러

### 역할 (트리니티)
| 역할 | 특징 | 스킬 |
|------|------|------|
| 🛡 탱커 | 높은 HP(240) + 피해 50% 경감 | 도발(어그로 강탈) |
| 💚 힐러 | 낮은 HP + 큰 마나 | 광역 치유 |
| ⚔ 딜러 | 높은 공격력 | 광역 폭발 |

훈련 골렘은 **어그로 1위**를 쫓아가 공격합니다. 탱커가 도발로 어그로를 잡고, 힐러가 살리고, 딜러가 녹이는 구조.

## 상태

✅ **Phase 0 완료** — 모노레포 + 실시간 동기화 검증 (최대 관문 통과)

✅ **Phase 2 완료** — 전투 기본기 (HP/마나, 공격, 스킬, 더미 처치/리스폰)

✅ **Phase 3 완료** — 역할 3종 (트리니티)
  - 탱커/힐러/딜러 역할별 스탯·스킬
  - 어그로(threat) 시스템 + 훈련 골렘 AI (추격·근접 공격)
  - 도발(어그로 강탈), 광역 치유, 피해 경감, 플레이어 사망/부활
